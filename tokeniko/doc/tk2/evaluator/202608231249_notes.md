## The frame — judge, never admit

The opening stake, agreed at once: the evaluator is a **pure function** — stores nothing, believes
nothing — returning **one verdict shape** for every caller: truth in [0,1] · status (proven / refuted
/ insufficient / INCONSISTENT reserved for logic) · **bindings** (every variable it solved, senses
included) · **derivation** (the premise chain, always). The author's summary: **the evaluator judges,
the brain admits** — a pass-through helper for the brain.

## One algorithm, no stages

The sharpening that killed a pipeline step («100% exactly this»): **WSD is not a stage.** An open
sense slot, a wh-gap, an unbound role are all the SAME problem, solved by the same search — **try
bindings, keep the one whose grounding survives the KB** (tkzip #10 generalized). The evaluator has
one algorithm:

1. **form check first** — the logic kernel, hardwired, INCONSISTENT reserved for violations of logic
   alone;
2. **bind-and-ground under the dual read** — every grounding reads both floors (stated cell + cosine)
   and names its source;
3. **chaining when direct grounding is silent**;

and **ABSTAIN is a first-class verdict at every depth — never guess** (the abstention invariant made
mechanical).

## The three closing stones

- **The search is budgeted.** Depth/time caps are db(r) parameters; a budget-out returns
  *insufficient with the depth stamped* — honest, never false.
- **Instinct may ORDER the search, never the verdict.** Micro-nn can rank which binding to try first
  (speed); accept/reject stays deterministic math. The fence from brain/heart holds inside the
  evaluator too: truth stays sacred, choice stays free.
- **Stake resolution is the evaluator's.** An arriving event is matched against staked forecasts
  (heart req. 17); «x came true / x broke» is the verdict that fires serendipity or disillusion.
