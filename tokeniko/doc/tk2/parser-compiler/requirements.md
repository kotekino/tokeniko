# parser/compiler — REQUIREMENTS

*What the one station must be. One line each. Evidence in the dated `_notes.md` beside this.*

1. **One station, one format** — tkzip is the only thing that crosses the boundary; internal scratch is private, never stored, never a contract; tk1's AST/LLC die as interfaces.
2. **The skeleton provider is a demoted, swappable proposer** — stanza kept for tokens/POS/deps (best-in-class, local); an implementation detail behind the lib boundary; its stumble is rag-in's case.
3. **The journey shields the misparse** — the evaluator's incoherence on fresh input flags parse-suspicion (mandatory second reader); below the floor the BRAIN asks by rendering the reading back; `original` stays verbatim so even a landed misreading is retreatable.
4. **Every zip carries a CONFIDENCE scalar** — «this zip IS what I received»: a calibrated aggregate of coverage · repairs-taken · self-round-trip; tk1 never had one.
5. **Calibration is the seventh micro-nn site** — corrections train it down, smooth dialogue up; it steers choice (proceed / rag-in / ask), never truth.
6. **The self-round-trip is escalation-only** — cheap signals are free bookkeeping; the second read fires only on ambiguity, plus lazy sleep spot-calibration; clean input costs ONE parse.
7. **The station is pure — context is an argument, never state** — anaphora, ellipsis, fragments resolve against caller-provided recent zips; zero hidden memory.
8. **Half-understood is legal, wrongly-understood is the sin** — beyond-format input yields a partial zip honestly marked (open variables + confidence), never a silently-complete nearest fit.
9. **Bidirectional** — the renderer (zip → faithful scaffold) lives in the same lib; parse and render symmetric; the round-trip is internal machinery.
10. **The fifty-sentence drill is the acceptance gate** — the no-abstention coverage bar set in advance, drilled before any officer builds.
