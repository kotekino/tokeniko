## One abstraction, many instances

Every named use shares one shape: **features in → a ranking or a scalar in [0,1] out → learned online
from the reward families** (intellectual + heart, brain req. 18). Therefore:

- **one tiny middleware** — small nets, numpy-scale, laptop-honest (no heavyweight stack);
- **an instance is config + weights stored as db rows**, epoch-stamped like derived points; training
  moves rows, never code — the everything-is-rows seam holds here too;
- instances differ by declaration (input schema · output kind · reward source), never by stack.

## The shared fence

One fence over all six, inherited from brain req. 17 and restated as the framework's law: a micro-nn
**ranks among already-legal options only** — never a verdict, never content, no provenance, so it can
never mint or admit a belief — and **a kb rule outranks it, always**.
