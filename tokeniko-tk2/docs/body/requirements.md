# body — REQUIREMENTS

*The interpreter of the db. Distillation session 2026-08-23 (author's ruling: evolves tk1, strong
base exists). One line each.*

1. **One body, embodied, bare metal** — settled and not re-litigated; one persistent process-family with its local MongoDB; finite hardware is a feature (the laptop/mini is the ceiling).
2. **The body is an INTERPRETER of the db** — kb (rw) · parameters (r) · hardwired-logic tables (r); the binary holds only the irreducible math (evaluator, loop, operators) and changes only when the math changes.
3. **Deploys are migrations** — development ships as scripts that write the db; the deploy machinery (`scripts/body/`) evolves from tk1's runbook.
4. **Boot = load the r-tables; a slow tick reconciles** — parameter edits land live, without restart.
5. **The body is the only extensible floor** — fixed at any moment, grown only through someone else (rules #12): new senses, new hardware, new capabilities arrive by hands not his.
6. **The processes stay separated** — mind (brain), surface (api/station), connectors (senses): separate lifecycles, the db as the only shared ground.
