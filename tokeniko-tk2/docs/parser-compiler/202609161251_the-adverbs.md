it changed the answer twice: once about where the set lives, and once about what a set that size

## THE RESOURCE CANNOT ANSWER THIS, AND THAT WAS MEASURED FIRST

The supersense settled the thirteen ambiguous markers a few hours earlier, so it was the obvious
first thing to try. It gives **nothing**:

- **WordNet files every adverb under ONE lexicographer class, `adv.all`.** 26 noun classes, 15 verb
  classes, one adverb class.
- **Adverbs have NO HYPERNYMS.** Zero, on every probe. R is structurally thin for them, and the
  taxonomy walk that would answer «is this a time adverb» does not exist in the resource.
- The **pertainym** — the adjective an `-ly` adverb derives from — separates DERIVED from UNDERIVED
  and not manner from epistemic: `quickly → quick` and `probably → probable` both have one.

So it is curation, and the only question was whether an open class can be curated at all.

## IT CAN, BECAUSE MANNER IS THE DEFAULT

Of WordNet's **3,767 single-word adverbs, 79% end in `-ly` and 73% carry a pertainym** — derived from
an adjective, describing the action. **A compiler that defaults to a manner box is right about the
overwhelming majority for free**, so the table holds only the EXCEPTIONS: the epistemic, the
evaluative, the discourse connectives, the non-`-ly` circumstantials. **106 rows.**

*That is what turns an open class into a curatable one — not a roster of adverbs, a roster of the
ones that are not what an adverb usually is.* And it is why the default must be COUNTED: a default
that cannot be told from a curated answer is the silently-complete nearest fit req 8 forbids, which
is the same distinction `db/0012` drew for the markers.

## THE RULE'S FIRST LIVE APPLICATION, AND IT MOVED THE ANSWER

By the second standing law these are structure: «however» compiles to a JOIN exactly as «because»
does, «probably» to a MODALITY exactly as «may» does. So the closed-class table is where they
belong — **and the Captain ruled otherwise, on a cost the principle does not see.**

**The closed-class forms are a STRUCTURE FILTER on D's vocabulary.** Sixty new forms would change
what D is built from, and the sealed base was built against the set as it stands. So: a separate
collection, the base untouched, the closed classes at 383 rows.

**He named the cost himself** — «what does this word compile to» now has two tables — and it is paid
by making only the ROSTER second. `compiled` here holds the identical vocabulary
`ClosedClassDoc.compiled` holds, so a caller asks one, misses, asks the other, and cannot tell which
answered. **If the exclusion set ever stops being load-bearing these rows merge upward and nothing
above notices.**

## THE CLASH CHECK PAID FOR ITSELF ON THE FIRST RUN

Two rosters are a cost; two rosters DISAGREEING is the cost becoming a defect. So `db/0013` refuses
at import any form the closed classes already hold — and the first draft held **eleven**, of which
**ten were already compiled CORRECTLY there**:

    so · yet · notwithstanding        already `join` — imply, and, and-concessive
    anywhere · everywhere · nowhere · somewhere   already `quantifier` — they quantify over PLACES
    inside · outside                  already a `box`, roles [location]
    besides                           already an exceptive `restriction`

**The finding is about this table's assumptions, not about the closed classes.** They are more
complete than the migration assumed, and the honest move was to delete eleven rows rather than argue
with them. *A roster written without reading the roster next to it is how one fact acquires two
homes.*

## AND THE ELEVENTH WAS A REAL GAP — TWICE

`however` had ONE closed-class row: `free_relative`, «however you do it». **Its discourse reading
had no row anywhere.** The same shape turned up immediately afterwards: `here`, `now`, `then` and
`there` read `{"kind": "entity", "resolve": "context"}` — right about the HEAD, silent about the
ROLE — so «They come HERE» left `here` unplaced in a sentence otherwise understood.

Both are closed-class forms, so neither can come to the adverb table. **And repairing them there is
FREE, which is the whole point**: `CLOSED_CLASS_FORMS` is a set of **FORMS**, so editing a row's
`compiled` column and adding a second row for a form already present both leave it at **268**. The
Captain's ruling against putting sixty NEW adverbs in the closed classes does not reach these two,
because no form arrives. That is `db/0014`, and its own check refuses to apply if the count moves.

## A MARKED NOMINAL OUTRANKS A BARE ADVERB FOR THE SAME BOX

«left EARLY in the MORNING» has two time expressions and one time box. Placing adverbs in token order
let `early` take it and pushed `morning` out — the same coverage and the worse reading. **The speaker
chose the marker**, so the marked nominal is the stronger evidence, and adverbs are now placed after
the nominals of their clause.

## TWO THINGS DELIBERATELY NOT COMPILED

**An EVALUATIVE adverb abstains, and it is not an oversight.** «Luckily he left» asserts that he
left; the speaker doubts nothing and is telling you how to feel. tkzip's prefix has an attitude
element and E2 put it there for exactly this — but what it holds is an ATTITUDE HOLDER, and an
evaluative adverb names none: it is the speaker's, and the speaker is the POV's business. So it is
recorded as an abstention rather than compiled into something it is not.

**A CONNECTIVE WITH ONLY ONE ROW ABSTAINS.** «However, he left» in isolation names a contrast with
something the sentence does not contain — usually the previous utterance, which is context and
therefore an ARGUMENT (req 7) that the call does not have. Inventing the missing operand would be
the silently-complete nearest fit.

## THE OTHER HALF OF THE MORNING: THE DRIFT THAT WOULD HAVE BEEN SILENT

The Captain ruled «fix it now, before any v7» on a gap found while pricing this work. `SpaceOrigin`
recorded the build label, the seal fingerprints and the policy version — **and not the closed-class
version**, although the closed-class forms filter D's vocabulary. A table migration could move under
a sealed base and nothing anywhere would disagree: same label, same seals, same policy.

It is **recorded rather than enforced**, and that is deliberate. A table may legitimately run ahead
of a base — E3 wrote four closed-class versions in one day without a rebuild and each was correct.
What must never happen is that the two disagree and nobody can see it.
