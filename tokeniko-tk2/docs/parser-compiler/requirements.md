12. **The 37 → 18 mapping has TWO HALVES, and they must not collide** *(found by the gate, 2026-09-15)* — a role that arrives with a MARKER (`location`, `time`, `instrument`, …) is the closed classes' business and lives in rows; a role that arrives by RELATION (`agent`, `patient`, `recipient`) is the compile core's and comes from `nsubj`/`obj`/`iobj`. The table proves the split by holding **no marker for `patient` or `experiencer`** — there is none in English. Asking the marker table for a relational role is a category error, and it was made twice in the gate's own first transcription.

13. **A joining word says whether its clauses are CLAIMED** *(closed classes v4, `db/0010`, 2026-09-15)* — «if» and «because» are the same `IMPLY` and differ only in assertion status (req 38), and nothing in the dependency tree separates them: both are `mark` on an `advcl`. So `asserts` is knowledge about the word and lives in the row — `both` · `neither` · `matrix` (a POV: the report is claimed, its content is not) · `ambiguous` («when», where only the theatre decides, and the station abstains). **The root is not claimed by being the root**: «if it rains I stay home» asserts neither half.

14. **A wh-word says WHICH slot it opens, and three of the five kinds are not boxes** *(closed classes v5, `db/0011`, 2026-09-15)* — `box` (when → time, where → location, how → manner) · `participant` (who/what: **the relation decides**, req 12) · `truth` (whether: the polar question) · **`antecedent` (why: there is no cause box to open — req 37 — so it asks for an unknown ROW implying the one asserted)** · `field` (whose: the possessor lives inside the record, req 26). **The same word asks in a root clause and describes in a relative one**, and only tk1's R5 walk separates them: nothing in the dependency does.

15. **What a marker means is settled by the SUPERSENSE of the words around it, and the rules are curation** *(closed classes v6, `db/0012`, 2026-09-16)* — «I swam in the pool» and «I left in May» differ in nothing a dependency tree can see, and everything in what kind of thing the nominal IS. WordNet files every synset under one of **26 noun and 15 verb lexicographer classes**, published and closed, so the table from a supersense to a tkzip role can be **complete** — the same argument that made UD the station's gate (req 10), arriving a second time at the other end of the mapping. The PRIMARY sense only (`db/0006`'s rule; a max over senses reads `pool` as a TIME). **`of` asks no dictionary at all** — the head's POS settles material from possessor, and the possessor is a FIELD (req 26), not a box. **A DEFAULT IS AN ANSWER AND IT IS COUNTED**: req 8 forbids the *silently* complete nearest fit, so an unchosen marker fills its box from the curation's best-first order and the zip records that nothing chose (`Compiled.defaulted`, req 4's input). **Named debt**: the supersense is read live from WordNet and sits outside the base's build fingerprint; its home is a `lexname` on `SenseVectorDoc`.

16. **A NAME IS ITS OWN POINT, AND IT IS FIVE QUESTIONS AND NOT ONE** *(the Captain, 2026-09-16, reopening the parked hole — E3b)* — *is this a name at all* (casing is an indicator and not a test: tk1's gate both admitted OOV gibberish spaCy labelled `GPE` and refused «kotekino», which is lower case and known) · *a name of WHAT* (person · public figure · organization · place · work · event) · *WHICH one* (Paris, France against Paris, Ontario — tk1 logged this and never solved it) · *have I MET it* (recognition against a names table, which is a different question from identification and is the one that carries identity) · *what it IS in a zip* (a type-centroid SEMANTIC vector plus a context-scoped IDENTITY uid, never merged). **The geographical half is CURATED and inherited** — tk1's places table, ~4.7M author-curated rows with two containment chains and a closed ~21-value `type` column that is an `is_a` statement, read lazily and never materialized. **The prominence half cannot be curated and is the ecosystem's first micro-nn** (micro-nn req 9). **An NER label is a CANDIDATE, never a verdict** — which is exactly what the micro-nn fence is allowed to rank. *This does NOT reopen req 2: entity recognition is not a UD task, has no UD relation, and stanza ships its own NER processor — so «stanza against spaCy on the same text» is a measurement E3b owes rather than a second opinion on a dependency parse.* Record: `202609160959_the-name-question.md`.

17. **THE KINDS OF NAME ARE OUR OWN INVENTORY, AND THEY ARE ROWS — NOT CODE, AND NEVER A THIRD PARTY'S** *(the Captain, 2026-09-16, answering open question 14)* — *«with our inventory as db (not code!), we can modify it keeping the logic: everything is KB. If we rely on a third party we lose this ability.»* **That is the first standing law's FRAME test, applied to a set that feels like law and is not**: «public figure» against «person» is a judgement about the world, revisable, and a roster needing a code change to grow would put the table back in code — the precedent is `ClosedClassDoc.word_class`, a string and not an enum for this exact reason. So BOTH halves are curation: the kinds themselves, and the map from an NER label to a kind. Only the reader is frame. **An NER label set could not be the frame anyway**, for four further reasons: seven of OntoNotes' eighteen (`DATE TIME PERCENT MONEY QUANTITY ORDINAL CARDINAL`) are not names but measurements the format already says, so adopting them gives tkzip a second way of saying what it has (the defect req 37's collapse was avoided for) · three (`GPE LOC FAC`) are one question for us, «is it in the places table» · **a kind must be reachable with NO label at all** («kotekino» gets `PROPN` and no NER type — tk1's recorded failure, repaired only by bolting on a second path) · and it is the shape the station already uses twice, at req 12 and req 15. **Prominence is a SCALAR on the resolution, not a kind**: «public personality» is a person who is prominent, and a company is an `organization` that is prominent. Made a kind, it would have to be decided before the thing is identified and would leave the micro-nn nothing to rank; made a number, it IS what the micro-nn ranks (req 16, E3b task 5).
