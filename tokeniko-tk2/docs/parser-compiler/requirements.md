*What the one station must be. One line each. Evidence in the dated `_notes.md` beside this.*

1. **One station, one format** — tkzip is the only thing that crosses the boundary; internal scratch is private, never stored, never a contract; tk1's AST/LLC die as interfaces.
2. **The skeleton provider is a demoted, swappable proposer** — stanza kept for tokens/POS/deps (best-in-class, local); an implementation detail behind the lib boundary; its stumble is rag-in's case. **[AMENDED 2026-09-15 — stanza is the provider because it TARGETS A STANDARD. `spacy-stanza` may be the API surface; spaCy's own models are neither a second opinion nor a fallback, because «stanza tries to be as close to UD2 as possible while spaCy is more creative» (the Captain) — two readers where only one is trying to be correct is one reader plus noise. **The second reader is UD2 itself**: 37 relations and 17 POS tags with published examples, checked relation by relation. «Close enough» is a measurement E3 owes, not an assumption it carries. Record: `202609151148_the-ud-gate-and-the-stations-edges.md`.]**
3. **The journey shields the misparse** *(shield (1), disagreement between skeletons, is DEAD — see req 2's amendment; shields (2) and (3) below are the real protection)* — the evaluator's incoherence on fresh input flags parse-suspicion (mandatory second reader); below the floor the BRAIN asks by rendering the reading back; `original` stays verbatim so even a landed misreading is retreatable.
4. **Every zip carries a CONFIDENCE scalar** — «this zip IS what I received»: a calibrated aggregate of coverage · repairs-taken · self-round-trip; tk1 never had one.
5. **Calibration is the seventh micro-nn site** — corrections train it down, smooth dialogue up; it steers choice (proceed / rag-in / ask), never truth.
6. **The self-round-trip is escalation-only** — cheap signals are free bookkeeping; the second read fires only on ambiguity, plus lazy sleep spot-calibration; clean input costs ONE parse.
7. **The station is pure — context is an argument, never state** — anaphora, ellipsis, fragments resolve against caller-provided recent zips; zero hidden memory.
8. **Half-understood is legal, wrongly-understood is the sin** — beyond-format input yields a partial zip honestly marked (open variables + confidence), never a silently-complete nearest fit.
9. **Bidirectional** — the renderer (zip → faithful scaffold) lives in the same lib; parse and render symmetric; the round-trip is internal machinery.
10. **The fifty-sentence drill is the acceptance gate** — **[EXTENDED 2026-09-15: the drill is the FORMAT's gate and stays one; the STATION's gate is UNIVERSAL DEPENDENCIES — every one of the 37 relations and 17 POS tags handled consistently against UD's own examples. And the Captain's 583 stored v1 journeys are NOT a gate at all — they are E9's no-regression ratchet material, usable here as evidence only.]** — the no-abstention coverage bar set in advance, drilled before any officer builds.

11. **The station consults the dictionary for SHAPE, never for MEANING** *(added 2026-09-15)* — the ported content lists become geometry with a nearest-anchor fallback, so «is this an implication verb?» is answered by the base rather than by a list; but the sense slot is emitted **OPEN** and the station never picks a sense.
