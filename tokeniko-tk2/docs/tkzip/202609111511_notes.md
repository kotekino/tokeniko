## The ladder

Rows must point at other rows — «I went to Genoa **to see** the sea», «**If** it rains, I stay
home». The obvious move is nesting (v1's `TKZipItem.content` is recursive) and it kills fixed size:
*how deep?* has no non-arbitrary answer.

**The Captain's answer, agreed as OQ8: name the rows.** `[Y = A AND B, Y IMPLY C]` — the Tseitin
transformation. Instead of nested parentheses, give every sub-expression a name and list them flat.
A zip is a **flat list of fixed-size rows**, some named, referring to each other by name. Arbitrary
depth, constant shape.

### A box may hold a row name — and what its vector is

If a box holds row `Y` rather than a word, the arithmetic still needs a vector for it. **Ruled: the
derived point of row Y** — req 12/16's composed point, the same layer the adverb rotation lives in.
So «he thinks the cat is cute» and «he thinks the cat is pretty» read near, because their embedded
thoughts do.

The Captain's addition, which is the reason the design works: *«it doesn't flatten everything — we
keep the rows for detailed analysis, like solving the equation where something is unknown (the
BINDING STATE), but still allow comparison operations on the geometry.»* Two readings of one object,
neither destroying the other.

### THE POV CORRECTION (the Captain)

The QM's example — «he thinks that the cat is cute» as two rows — was **wrong**, and the correction
is structural: *«that enters the special case of point of view, so it's not a real 2-rows sentence,
because the thinking-who is flattened in the POV of the first sentence.»*

| row | POV | patient | complement |
|---|---|---|---|
| 1 | **he / think** | cat | cute |

One row. The thinker rides the row's point of view, exactly as the excel draft has it («my cat is
cute» → POV `me / think`).

**What follows — the ledger's «POV beyond depth 1» made concrete:** POV holds ONE attitude, so «he
thinks that I believe the cat is cute» needs a second row with its own POV. Depth 1 → a field pair;
depth 2+ → named rows. *(Revised later the same session by case H — see α.)*

## THE COLLAPSE — the Captain's rule, and what it destroyed

The QM proposed **two fields**: a truth-functional `operator` (closed by mathematics) plus a
`relation` field for the non-truth-functional links (THAT, RESULT, PURPOSE, CAUSE), citing v1, which
carries `op=AND` **plus** a separate `cause` field.

**The Captain refused it, and gave the rule that governs the rest of the epic:**

> *«If we can collapse in math everything we can, and collapse in fields (POV) or variables
> (Y = statement1) what remains, we have simplified our lives. THAT and all the relations are hardly
> manageable: you can have endless chains of relations and tk2 doesn't univocally understand nor get
> real information, because he can't compare to his KB.»*

Applied honestly, everything collapses:

| | collapses to |
|---|---|
| «if» | `IMPLY` |
| «and» | `AND` |
| «or» | `OR` / `XOR` |
| «but», «although», «regardless of» | `NIMPLY` — the Captain's own worked example: *«people think Y NOT IMPLY I believe in god»*, `A ∧ ¬B` |
| «unless» | `IMPLY` + `NOT` |
| «before», «after» | the **theatre** |
| «that» | POV field · named variable |
| «according to X» | POV field — *X / say* |
| «painted the door **red**» | second row + IMPLY + theatre |
| «because» | ↓ |
| «to see the sea» | ↓ |

### CAUSE dissolves — the Captain's argument

> *«The cause is implication + time theatre. It rains (t-1) implies NOT (I go outside). It can't be
> vice versa, because imply has one direction and time is unequivocal. If it doesn't rain, it's not
> granted that I go outside or not, so the implication is still true.»*

And the premise that licenses it, stated so it is not assumed silently:

> **«The cause of anything, if the world is deterministic and for our purpose it is, is cause that
> implies effect.»**

**The QM's objection, and why it was wrong.** The QM argued that since «because» is factive — both
halves asserted — `A→B` is entailed by `A∧B` and therefore vacuous, so something is lost.

**The Captain refuted it with a distinction the language itself marks:** *«"I stayed home ONLY
because it rained" is the logical equivalence — and "only because" is the language equivalent of "if
and only if", IMPLY and CONV together.»*

English confirms it exactly:

> «I stayed home **because** it rained — but I'd have stayed anyway, I was tired.» — **coherent**
> «I stayed home **only because** it rained — but I'd have stayed anyway.» — **contradictory**

So plain «because» **is** the one-directional implication, and the counterfactual it does not support
is the one it never claimed. What it adds over the bare conjunction is that it **licenses
generalization to a rule** — the extractor's fuel, which the conjunction does not give.

| | |
|---|---|
| «I stayed home because it rained» | `rain(t−1) IMPLY stay(t)`, both rows **asserted** |
| «I stayed home **only** because it rained» | `rain(t−1) EQ stay(t)` |
| «**If** it rains, I stay home» | `IMPLY`, rows **not asserted** |

**The piece that makes it work costs nothing:** «because» and «if» differ in whether the rows are
*asserted*, and assertion status is req 2's binding state — task 3's subject, needed anyway.

**A capability the dissolved form buys that a `CAUSE` field could not.** «It must have rained,
**because** the ground is wet» is *evidential*, not causal. Under this encoding the implication runs
wet(t) → rained(t−1) while the theatre runs t−1 → t: **the two directions disagree, and that
disagreement is the signature of abductive reasoning.** A `reason`/`result` flag could never see it.

### «only» generalizes — a family, and the seam applied a second time

| one-directional | bidirectional |
|---|---|
| if | if and only if |
| because | only because |
| causes | only causes |

**«only» is not an operator — it is the marker that converts `IMPLY` into `EQ`.** So the schema needs
one pair, not three families, and the words that select between them (*only · iff · solely · just in
case*) are **`language_closed_classes` rows**. Same seam as the role markers: **the operator is
frame, the words that mark it are knowledge.**

The Captain's own falsification test: `smoke EQ cancer` is **false** (cancer has other causes,
smoking other effects) while `smoke IMPLY cancer` survives as a generic with fuzzy truth. The logic
rejects the over-strong reading by itself — no special case.

### PURPOSE dissolves too

| row | POV | content | joins |
|---|---|---|---|
| **Y** | **me / want** | me · see · sea | |
| 1 | — | me · go · Genoa | **Y IMPLY 1**, t(Y) < t(1) |

Wanting asserted, going asserted, **seeing never asserted** because it sits inside the `want` POV.
OQ3's recorded unsoundness — *«it would derive that an intended outcome occurred»* — is gone, since
modus ponens reaches the wanting and not the seeing.

**Nothing survives the collapse. There is no relation field.**

## THE OPERATOR SET — do not trim

The QM proposed storing the six operators English marks and normalizing to three. **The Captain
refused, and the argument is the standing law:**

> *«The operators are supposed to work on the math/geometry first. tkzip carries ALL the rules that
> are not frame. The math behind an operator is cheap — standard formulas over the vectors — so why
> trim when the support is cheap? Then, for the natural-language analysis, support the six English
> ones.»*

**The QM had put a contingent fact about English into the FRAME**, which is precisely what the
standing law forbids. Restricting the format to what English marks would restrict what tokeniko can
**think** to what English can **say** — and he computes operators nobody uttered (self-talk, derived
thought, chained theorems).

| | lives in | closed by |
|---|---|---|
| **the operator set** | code — frame | **mathematics**, therefore complete |
| **which ones English marks** | `language_closed_classes` rows | evidence, therefore grows |

**The honest count is TEN, not sixteen.** Six of the sixteen binary functions are degenerate
(`TRUE`, `FALSE`, `A`, `¬A`, `B`, `¬B`) — they ignore an input and are not joins:

`AND · NAND · OR · NOR · XOR · EQ · IMPLY · NIMPLY · CONV · NCONV`

plus per-row negation, which is a row property rather than a join.

**A QM error the Captain's refusal caught.** The QM had proposed fusing `CONV` into `IMPLY` on the
grounds that row order gives direction. **But row order carries SCOPE** (below), so it is not free to
swap: reordering to express direction would silently change scope. **`CONV` stays.**

**The caveat that goes on the record.** An operator does two jobs, and they are not equally cheap:
*truth* is a fuzzy formula over [0,1] and all ten are genuinely free; *composition* — folding two
rows' derived points into one (req 12) — has a natural reading for `AND`/`OR`/`NOT` and **no obvious
one for `XOR` or `NAND`.** Declare all ten in the frame, implement all ten in truth, and let the
derived layer implement what it can define and **abstain visibly** on the rest, rather than shipping
a formula nobody can defend.

**Normalization survives as a separate thing** — a canonical form used only at comparison time, so
`A NIMPLY B` and `A AND ¬B` compare as one thought while still rendering as «regardless» and
«and not». Faithful in storage, uniform in arithmetic. **Not a trim.**

## SCOPE — run bench-first under the new instruction

### Why it was live

Task 1 ruled the quantifier into the **noun-phrase record**, which distributes quantifiers across
boxes and leaves **nothing saying which applies first**. Both readings of «every man loves a woman»
produced the identical zip — a gap opened that morning and closed the same day.

### The bench (audited and approved by the Captain before any testing)

| # | case | the two readings |
|---|---|---|
| A | «Every man loves a woman» | ∀>∃ · ∃>∀ |
| B | «All that glitters is not gold» | ¬∀ · ∀¬ |
| C | «Every student must pass» | ∀>□ · □>∀ |
| D | «Only smoking causes cancer» / «Smoking only causes cancer» | scope over cause vs over effect |
| E | «Every teacher gave some student a book» | three quantifiers |
| F | «If every cat is hungry, I feed **them**» | scope crosses rows |
| G | «John doesn't have a car» | ¬∃ · ∃¬; definiteness as scope |
| H | «He thinks **a cat** is in the garden» | de dicto · de re |

**What «handle» means:** both readings expressible as different zips · the difference visible to the
evaluator, not merely stored · the single-quantifier sentence pays nothing · composes with the
noun-phrase record, row order, POV and named rows · the renderer can speak it back.

### The candidates and the result

| | A | B | C | D | E | F | G | H |
|---|---|---|---|---|---|---|---|---|
| **(a) box order decides** | ✘ | ✘ | ✘ | ✘ | ✘ | ✘ | ✘ | ✘ |
| **(b) row order = prenex** | ✔ | ✔* | ✔* | ✔ | ✔ | ✔ | ✔* | ✘ |
| **(c) scope rank per record** | ✔ | ✔* | ✔* | ✔ | ✔ | ✘ | ✔* | ✘ |
| **(d) both** | ✔ | ✔* | ✔* | ✔ | ✔ | ✔ | ✔* | ✘ |

**(a) is dead on case A** — and it matters because **(a) is what we get by doing nothing.** Freezing
the schema without answering this *chooses* (a).

**\* THE EXTENSION all three need.** Cases B, C and G are not about quantifiers: they are **negation**
and **modality** scoping against them. So whatever orders quantifiers must order those too — which is
what prenex normal form actually is, `¬∀x◇∃y(…)`, a prefix of *all* scope-bearing elements. *(It also
explains v1's `NEGATED_UNIVERSAL`: with no prefix, v1 patched one ¬/∀ combination into the quantifier
enum. A prefix handles the class.)*

### RULED: (b) — row order = scope order

Not because it wins the matrix — (d) matches it and is cheaper on A and E — but on a structural
argument, and the Captain's lean was the same:

- **Cost of (b), stated:** almost every sentence carries a determiner, so almost every sentence
  doubles in rows, the content row's boxes hold *variables* rather than nouns, and every comparison
  of a quantified sentence pays an indirection (the variable dereferences to its binder's derived
  point — a rule already made).
- **Cost of (d), stated:** two mechanisms, and ranks that must order **heterogeneous** things — a
  quantifier in a box, a negation field, a modal field, a POV field — so an integer scattered across
  five places in the row has to be globally comparable. The third standing law weighs against it.
- **What tipped it:** req 2 says *an unbound slot is a variable*, and evaluator req 5 says sense
  slots, wh-gaps and unbound roles are **one problem**. Under (b), quantification becomes the **same
  machinery** as questions, equations and Tseitin naming: a box holds a variable, a row binds it.
  **One mechanism, four jobs.** Under (d) a quantified noun phrase is *not* a variable, so the
  evaluator must synthesise one the schema never wrote down.

### CASE H — not a discriminator, a finding; and a ruling revised

All four candidates failed H for one reason: **POV was a flat field, and a field has no position in a
scope ordering.**

The Captain's first ruling was that *inexpressible* is acceptable — *«not knowing is good and
triggers a question; what tk is not understanding, he doesn't make up.»* **The QM pushed back, and
the push-back was accepted.** The principle is right; this case is not an instance of it:

- **Honest abstention** records that something was not resolved, drops confidence, and the brain may
  ask.
- **What a flat POV actually produces is silent commitment.** The binder sits at the top level, so
  the zip reads *there is a cat, and he thinks it is in the garden* — **de re, asserted**, with no
  mark that a choice was made. «He thinks a **unicorn** is in the garden» would put a unicorn into the
  KB as existing. Same class of error as the IMPLY-encoding of purpose that OQ3 threw out: deriving
  something the speaker never claimed.
- **And it overrides the Captain's own reading.** He said he would read the sentence as *«one generic
  cat is in the garden»* — that is the **de dicto** reading, the one the flat field cannot express.

**α RULED: the attitude takes a prefix position.** It costs nothing — it is the extension already
accepted for negation and modality, applied to a third operator:

```
de dicto:   [he thinks] [∃X cat] | X in garden      ← no cat asserted
de re:      [∃X cat] [he thinks] | X in garden      ← cat asserted
```

The flat POV field survives as **shorthand for one fixed prefix position**, so «my cat is cute /
POV: me·think» still writes as one field. One mechanism, with a default spelling.

*The Captain: «I was wrong in understanding the problem and THAT'S why you being so pedantic and
sharp helps me a lot.»*

## CONTEXT / DOMAIN — requirement 6

*«Scope rides inside (who · in what context), so a contextual defeat is never relearned.»*

Run the same way: the bench was audited first, and the hypothesis — *what survives the collapse
behaves like a prefix operator* — was stated before testing.

| case | verdict |
|---|---|
| «**In 1990**, Germany reunified» | **collapses** → the `time` box; the theatre projects from it |
| «**According to Anna**, …» | **collapses** → POV (reportative — v1's `attitude.klass` has the category) |
| «Birds fly, **but penguins don't**» | **collapses** → generic quantification + `is_a` specificity; no framework marker in either clause, the format contributes nothing |
| «**In Italy**, you drive on the right» | **survives** |
| «**In chess**, a bishop moves diagonally» | **survives** |
| «**As a doctor**, I disagree» | **survives** |
| «**Legally**, he's still married» | **survives** — the anchor case |

**The two marked *unclear* at bench time, resolved by separating tests rather than by argument:**

- **«In Italy» is not the `location` box.** «**In Italy**, you may drive **in France** with a foreign
  licence» — both present, different jobs; one box cannot hold both. It is a **jurisdiction**.
- **«In chess» is not word-sense selection.** «In chess, **castling** is legal» has no sense
  ambiguity — castling exists nowhere else — and still needs a framework. *(The sense benefit is a
  consequence, not the mechanism: with the domain in the prefix, the evaluator has it in hand when
  binding the sense variable.)*
- **«As a doctor» is independent of POV.** «Anna thinks that, **as a doctor**, she disagrees» carries
  both, neither reducible to the other.

**What survives is ONE thing: a `domain`.** It scopes over a proposition, it nests («Legally, in
Italy, he's still married»), and it is not truth-functional. **Requirement 6 therefore needs no new
machinery** — and it does the job it was written for:

> «**As a doctor** I disagree; **as a father** I understand.»

Two contradictory positions, both held, **not a KB contradiction**, because each is indexed to its
domain. Rules reqs 6–7 exactly: *defeat in context, never deletion; an open conflict is a legal state.*

**Three checks run before calling it:**
1. **What fills a domain?** A concept — *law, chess, Italy, medicine* — so a domain row is an
   operator plus a nominal record: **the same shape as a binder row.** No new row type.
2. **Does it need a TYPE** (jurisdiction · game · capacity · framework)? **No.** Nothing reasons
   differently across them; the evaluator treats every one as *«P holds indexed to D»*. A type column
   would be a category-3 set wearing a list's clothes — the same trap as the morning's typed `other`.
3. **Does it open a list?** No: the **operator** is one (frame) · the **marker words** (*legally, in,
   as, under, per*) are rows · the **fillers** are any concept (open, geometry).

## THE PREFIX — five elements, approved

`quantifier · negation · modality · attitude · domain`

By the same law that governs the roles and the operators, **this set is frame and must be
exhaustive.** The QM's one stated doubt: **«only»**. It clearly scopes, and has been treated as (i)
the IMPLY→EQ marker and (ii) a restriction on a binder (`only X` = ∀y(P(y) → y=X) — quantification
plus identity, already in the prefix). Both readings look like collapses, but this was tested on four
sentences and «only» is the exact word v1 dropped entirely (req 8).

**Ruled: five approved, and «only» goes on the fifty-sentence drill with its own cluster.**

## WHAT TASK 3 INHERITS AND MAY NOT RE-DECIDE

1. **Modality cannot be a flat clause field** — it scopes (case C), so it takes a prefix position.
2. **Assertion status is load-bearing** — it is what separates «if it rains I stay home» from «I
   stayed home because it rained».
3. **The flat POV field is shorthand for a prefix position**, not an independent mechanism.

## ONE SUPERSESSION

Requirement 29, written this morning, said secondary predication is *«a second row joined by an
explicit RESULT operator»*. **RESULT dissolves with CAUSE**: «painted the door red» is
`paint(t−1) IMPLY red(t)`, both asserted. OQ5's original condition — *an explicit operator, since
temporal succession is not causation* — is met **better**, because implication is the link and the
theatre is the order, and bare succession still derives nothing. Req 29 is rewritten, not kept beside
the new form.
