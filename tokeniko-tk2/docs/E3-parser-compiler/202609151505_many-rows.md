*One content row per CLAUSE, related by joins, attitudes and shared variables. **20 of 25 UD cases

## THE THREE-WAY DISTINCTION, COMPILED

| sentence | operator | halves | join |
|---|---|---|---|
| «if it rains I stay home» | `IMPLY` | **EMPTY** | claimed |
| «I stayed home because it rained» | `IMPLY` | **claimed** | claimed |
| «it rained and I stayed home» | `AND` | claimed | claimed |

**One operator set, no relation field, three distinguishable zips.** This is requirement 38 and
`_Claimable`'s own docstring — *«that last line is what separates «because» from «if»: same IMPLY,
rows claimed or not»* — arriving from a dependency parse rather than from a hand-compiled fixture.

## IT NEEDED A MIGRATION FIRST, AND THAT IS THE FINDING

Version 3 gave «if» and «because» the **identical** `compiled`:

    if        {"kind": "join", "operator": "imply"}
    because   {"kind": "join", "operator": "imply"}

The operator is where they AGREE. Nothing in the dependency tree separates them either — both are
`mark` on an `advcl`. So the assertion status is knowledge about the WORD, and it belongs in the row:
**`db/0010`, version 4**, adds `asserts` to every joining word.

    both      30 forms   «because», «although», «since», and every coordinator
    neither   11 forms   «if», «unless», «whether», «in case» — the supposition shape
    matrix     2 forms   «that», «how» — the main clause is claimed, the subordinate one is not
    ambiguous  4 forms   «when», «once» — and it says so rather than picking

**«WHEN» IS GENUINELY TWO WORDS.** «When it rains I stay home» asserts no rain; «When I arrived she
left» asserts the arrival. Same word, same relation, and only the tense and the theatre tell them
apart. It carries `asserts: "ambiguous"`, the station **abstains**, and the abstention is named — the
same treatment as `'d` and the thirteen markers, for the same reason: *a row that picked one would be
a lie the compiler could not detect.*

## THE FOUR SHAPES

**A JOIN.** «She was reading or writing» → two content rows and a `JoinRow` naming its operands. Row
order is the order the speaker used, because row order carries scope (req 35).

**AN ATTITUDE, NOT A JOIN.** «He says that you swim» → an `AttitudeRow` with a holder and a verb,
scoping the inner row. **The saying is claimed; the swimming is not**, and nothing in the zip says it
is. `verb` is a key rather than an enum member: attitude verbs are open, so the classification is
nearest-anchor geometry over a small anchor set and never misses the verb nobody thought of (req 55).

**A SHARED VARIABLE, NOT A JOIN.** «The cat that sleeps is mine» is ONE cat described twice — the
relative pronoun IS the variable, not a third participant, which is why the sentence now compiles
whole. Req 36's single binding mechanism doing the work a second box would fake.

**AND `xcomp` IS DELIBERATELY NOT A CLAUSE.** «You like TO SWIM» is one predication with a controlled
subject: nobody asserts that you swim. A second row would put an unasserted proposition in the zip
with nothing marking it unasserted — **the one thing the truth slot exists to prevent**.

## THE BUG WORTH RECORDING: THE ROOT IS NOT CLAIMED BY BEING THE ROOT

The first draft set `truth = CLAIMED` on the root before reading any joiner. That is backwards, and
«if it rains I stay home» is the sentence that shows it: **the main clause is the root, and it is not
asserted either.** Only the conditional is. Truth is now decided AFTER every join has spoken — a row
is claimed unless a join left it unasserted.

*Getting this wrong would have put «I stay home» into the KB as a claim the speaker never made,
which is the failure mode the whole truth-slot design exists to prevent. It was found by looking at
the output of the sentence the requirement is written about.*

## WHAT REMAINS — five cases, three gaps, all named

    « I talked to my friend in the park »  75%   two ambiguous markers
    « Last night , I swam in the pool »    71%   one ambiguous marker
    « when do you sleep ? »                75%   a wh-word OPENS a box; WHICH box is unsettled
    « if you know who did it , tell me »   88%   an embedded question
    « he says that you like to swim »      86%   the xcomp's own verb, correctly not a row

The first two are the head-verb geometry, which needs the dictionary in the loop. The wh-cases need
a rule that says which box a wh-word opens. Neither is hidden: every one of them reports its
unplaced words, and the coverage floor is held by a test so a change that lowers it has to say why.
