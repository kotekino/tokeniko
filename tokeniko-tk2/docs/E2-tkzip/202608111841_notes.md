## The question that opened it

The author: **the zip format decides every later decision, so it comes before planning.** Agreed —
and the §2 microscope evidence points the same way: almost every lead is a SLOT failure, not a logic
failure (dropped conjuncts, «only» lost, modality lost, THAT-complements flattened). The format had
nowhere to put them.

## Fixed size — settled, and for a sharper reason than expected

First framing offered: does fixed vs variable decide *computability*? **No.** Variable size is
perfectly computable; what you lose is **comparability** — two zips stop comparing in O(1) by
geometry and start needing structure traversal, i.e. graph matching instead of cosine.

Author's position, adopted: **fixed will be painful and is immensely valuable.** The pain does not
disappear, it MOVES — into deciding which slots exist. That is the real cost of the decision, and it
is a cost we can pay deliberately rather than discover.

## Computing vs matching

Matching answers *is this known*. Computing — folding truths through the operator tree over an array
of zips — **derives what nobody ever said**. That is the whole reason the array is worth having.

## THE CENTRAL MOVE: an unbound slot is a variable, not a zero

The author: what is not a truth (KB fuzzy [0,1]) is a **variable**. This is already latent in v1 —
the wh-gap, and INSUFFICIENT-vs-FALSE — but v1 has no way to *carry* it.

Consequences, which is where the session earned its keep:

- **One object, three readings.** All slots bound → an ASSERTION. One unbound → a QUESTION.
  Unresolved → an **EQUATION**. Not three types; one shape read three ways.
- **An equation is the memory of an unfinished thought.** It persists. He can put a thought down and
  pick it up when the KB closes it.
- **An equation asserted true is SUPPOSITION** — the way he reasons inside a scenario without
  believing it. This is how the existing reductio loop generalises into a primitive.

Top benefits of that skill, agreed: (1) reductio as a primitive — assume ¬P, derive absurdity, keep
P; (2) counterfactuals — reason inside «if I were wrong about X» and retract without touching belief;
(3) planning — a goal-bound equation is «what would have to be true».

The author sharpened (3): planning is **an urge**. «I ignore the solutions for equation f(x) — how do
I retrieve them? memory? ask?» So **the unbound variable IS the urge**, and the choice of memory-vs-ask
is only which source might bind it. That is the volitional layer falling out of the format instead of
being bolted beside it.

## Scope travels inside

A defeat decided in one context must not be relearned tomorrow, so the **context (the user + his
properties) rides inside the equation**, not in metadata beside it.

## The fourth reading that isn't one

Offered: if actions are zips, the format must also denote an ACT. **The author refuted it** — the act
is a verb, and verb→category is *semantic*, so the same zip is simply CONSUMED by one of the
hardwired categories. The format needs nothing extra; only the dispatcher is semantic. Dropped.

## A standing tension, named not resolved

v1's WSD ladder (Lesk → curated `preferred` → centroid → frequency) is **hardcoded policy**, and
every microscope pass patches it by hand — batch 3 landed 21 curated rulings today. The author:
hardcoding is correct FOR TK1 (it is what makes this conversation possible), but tk2 should **add
knowledge to choose the meaning** rather than fix an order. The KB-native form of that is: pick the
sense that makes the sentence consistent with what he already knows — which is the equation again,
solving for the sense variable. His experience, in that design, is exactly what the microscope passes
are producing now.

## Not to be forgotten

Verb senses are the weakest layer measured so far («the cat is sleeping» compiled *dormant.s.02*,
«lying with head on paws as if sleeping»). **If actions are zips, a wrong verb sense is a wrong
ACTION** — not merely a wrong word. That raises the stakes on the verb half of the format.
